# TaskFlow — DevOps Learning Project

## Project Overview
TaskFlow is a task-management web application built while learning the
SOFT806 course concepts from Weeks 1–6.

## Project Goal
Build a working full-stack application and progressively apply:
- Agile planning and Kanban
- Git and GitHub collaboration
- Development environment and package management
- Django REST Framework backend
- React frontend
- Docker and Docker Compose

## Planned Features
- Create a task
- View all tasks
- Update task details
- Mark tasks as completed
- Delete a task

## Planned Technology Stack
- Frontend: React
- Backend: Python and Django REST Framework
- Version control: Git and GitHub
- API testing: Postman
- Containers: Docker and Docker Compose

## Learning Approach
Each feature will be developed incrementally, tested, documented,
and committed to Git.

## Project Status
Week 1 — Planning and DevOps foundations.

## Development Workflow

TaskFlow follows a feature-branch workflow.

1. Create a feature branch for each change.
2. Make and test the change locally.
3. Stage and commit the changes using Git.
4. Push the feature branch to GitHub.
5. Open a pull request for review.
6. Merge the change into main after review.

## Current Learning Progress

- Week 1: DevOps foundations and project planning.
- Week 2: Git, branching, commits, and pull requests.
